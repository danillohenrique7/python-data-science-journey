# Python Data Science Journey

Este repositório documenta minha jornada de aprendizado em **Python, Análise de Dados e Machine Learning**.

Meu objetivo é desenvolver habilidades práticas em programação, tratamento de dados, estatística e construção de modelos de Machine Learning, registrando minha evolução por meio de exercícios e projetos.

##  Conteúdos estudados

### 01 — Fundamentos de Python
Exercícios envolvendo:
- Listas e dicionários
- Estruturas condicionais e laços de repetição
- Funções e validação de dados
- Cálculos e relatórios de vendas

### 02 — Pandas
Exercícios envolvendo:
- Criação e manipulação de DataFrames
- Seleção e filtragem de registros
- Identificação e tratamento de valores ausentes
- Leitura e exportação de arquivos CSV e Excel
- Análise de vendas e cálculo de indicadores

### 03 — NumPy
Exercícios envolvendo:
- Arrays e matrizes
- Operações vetorizadas
- Estatísticas com diferentes eixos (`axis`)
- Filtros booleanos
- Tratamento de valores ausentes (`NaN`)
- Análise de faturamento

## Tecnologias utilizadas

- Python

- Git e GitHub
- Visual Studio Code

## Como executar os exercícios

É necessário ter o Python instalado e as bibliotecas Pandas, NumPy e OpenPyXL.

Instale as dependências:

```bash
python -m pip install pandas numpy openpyxl
```

Para executar um exercício, entre na pasta correspondente e utilize:

```bash
python nome_do_arquivo.py
```

**Observação:** os exercícios que utilizam CSV e Excel devem ser executados a partir da pasta `02-pandas`, onde estão seus arquivos de entrada.
